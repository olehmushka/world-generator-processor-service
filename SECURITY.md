# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, report
it privately using one of the following:

* [GitHub Security Advisories](../../security/advisories/new) for this repository
* Email: olegamysk@gmail.com

Please include as much detail as possible (steps to reproduce, potential impact, suggested fix if
any) so the issue can be triaged quickly. You can expect an initial response within a few days.
